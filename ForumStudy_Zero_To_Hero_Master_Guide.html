🧠 Chapter 0: The Absolute Beginner's Mental Model

Before reading code, you must understand how all parts fit together. If you memorize code without a mental model, you stay confused. When you understand the model, you become a hero.

🍽️ 1. The Restaurant Analogy (Client vs Server)

Frontend (The Dining Room): What the customer sees—the tables, menus, and buttons (React + HTML/CSS).

Backend API (The Waiters): Takes orders from the dining room, validates requirements, and runs to the kitchen (Express routes & controllers).

Database (The Kitchen Pantry): The permanent storage where all ingredients and customer bills are recorded safely (MySQL).

🔁 2. The 3-Tier Layered Architecture

Route: The URL door (e.g., POST /api/auth/login).
Validation: The bouncer inspecting your ticket before entry (express-validator).
Controller: The receptionist receiving the request body and coordinating the response.
Service: The business logic brain performing passwords hashing, SQL execution, and Gemini AI calls.

🧭 3. What are Vector Embeddings?

Computers cannot understand the concept of "debugging a React state bug". They only understand numbers. A vector embedding converts text into a list of 1,536 coordinates on a hyper-dimensional globe. Words with similar meanings land near each other. Cosine similarity simply calculates the compass angle between those two points!

📚 4. What is RAG (Retrieval-Augmented Generation)?

Standard AI guesses when asked about your private class notes. RAG solves this: 1. We chop your PDF into 900-character paragraphs (chunks).
2. When you ask a question, we find the 5 most relevant paragraphs.
3. We give those paragraphs to Gemini and say: "Answer strictly using these excerpts, and cite the chunk numbers." Zero hallucination!

backend/db/schema.sql
Database DDL (MySQL) • DATABASE · SCHEMA
135 lines
❓ WHY IS IT HERE?
Enforces strict relational integrity, primary keys, cascading deletes, unique constraints, and B-Tree indexes at the database engine level so corrupt or duplicate data can never enter the system.
⏱️ WHEN DOES IT RUN?
Executed during database setup and schema migrations before the backend server begins accepting HTTP requests.
⚙️ HOW DOES IT WORK?
Uses MySQL InnoDB engine with utf8mb4 encoding, defining foreign keys with ON DELETE CASCADE and FULLTEXT indexing for title/content search.
💡 Beginner Concept Spotlight
Primary Keys vs. Foreign Keys: A Primary Key is like a citizen national ID (uniquely identifies a single row). A Foreign Key is a reference pointing to another table's Primary Key (like writing down your parent's ID). ON DELETE CASCADE means if the parent is removed, child records are automatically cleaned up.
⚠️ Junior Developer Trap / Common Gotcha
Never store plain text passwords in the database! Notice the password_hash VARCHAR(255) column designed specifically for 60-character bcrypt strings.
🎯 Technical Interview Pro-Tip
Q: Why is question_hash used for routing instead of question_id? A: Sequential integer IDs (e.g. /question/1, /question/2) expose business metrics (total questions asked) and allow competitors to scrape the entire database with a simple loop. 16-character cryptographic hashes prevent scraping and enumeration attacks.

backend/db/config.js
Database Connection Pool & Query Runner (JS) • DATABASE · CONFIG
39 lines
❓ WHY IS IT HERE?
Opening and closing TCP connections for every HTTP request is slow and crashes the database. A connection pool reuses open connections. safeExecute guarantees all queries use prepared statements.
⏱️ WHEN DOES IT RUN?
Connection pool initializes on server boot; safeExecute executes every time any service queries MySQL.
⚙️ HOW DOES IT WORK?
Uses mysql2/promise createPool(). safeExecute checks that SQL queries are non-empty strings and parameters are arrays/objects before executing.
💡 Beginner Concept Spotlight
What is a Connection Pool? Think of it like a fleet of rental cars at an airport. Instead of buying a new car every time someone arrives, people borrow an idle car, drive to their destination (run query), and return it to the lot (release) for the next traveler.
⚠️ Junior Developer Trap / Common Gotcha
Never use string concatenation or template literals like `SELECT * FROM users WHERE id = ${id}`! Always pass parameters through safeExecute(sql, [id]) with ? placeholders.
🎯 Technical Interview Pro-Tip
Q: How does parameterized execution prevent SQL injection? A: It sends the SQL query structure and the user data to the database in two separate protocol packets. The database compiles the SQL statement first, meaning user input is strictly treated as literal data and can never alter query logic.

function calculateCosineSimilarity(vecA, vecB) {
  if (!vecA || !vecB || vecA.length === 0 || vecB.length === 0) return 0;
  const len = Math.min(vecA.length, vecB.length);
  let dotProduct = 0, normA = 0, normB = 0;
  for (let i = 0; i < len; i++) {
    dotProduct += vecA[i] * vecB[i];
    normA += vecA[i] * vecA[i];
    normB += vecB[i] * vecB[i];
  }
  const magnitude = Math.sqrt(normA) * Math.sqrt(normB);
  return magnitude === 0 ? 0 : dotProduct / magnitude;
}
